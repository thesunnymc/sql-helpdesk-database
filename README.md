# sql-helpdesk-database

Project objective is to design and implement a relational database for a Helpdesk Ticketing System. It should store information about users, tickets, issues, priorities, and resolutions. This demonstrates SQL schema design, normalization, queries, and IT support workflows.

## Features
- User management (Admins, Agents, Customers)
- Ticket tracking with priorities and statuses
- Categorization of issues
- Resolution logging
- Example queries for reporting
